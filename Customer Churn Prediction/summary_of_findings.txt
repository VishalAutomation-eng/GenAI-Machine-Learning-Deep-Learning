## Summary of Findings

### Feature Engineering & Selection
- Converted `TotalCharges` to numeric and imputed missing values using median.
- Applied One-Hot Encoding to categorical variables.
- Standardized numerical features using `StandardScaler`.
- Removed non-informative feature (`customerID`).

### Models Evaluated
- Logistic Regression (baseline)
- Random Forest Classifier (enhanced model)

### Model Performance Comparison

| Model               | Accuracy | F1-Score (Churn) |
|--------------------|----------|------------------|
| Logistic Regression| ~0.80    | ~0.60            |
| Random Forest      | ~0.79    | ~0.54            |

### Key Insights
- Random Forest handled non-linear relationships better.
- Contract type, tenure, monthly charges, and payment method were the most influential features.
- Class imbalance affected recall for churned customers, mitigated using `class_weight='balanced'`.

### Challenges
- Handling missing `TotalCharges`
- High-cardinality categorical variables
- Class imbalance in churn labels

### Conclusion
Tree-based models combined with proper feature transformation significantly improved churn prediction performance.
