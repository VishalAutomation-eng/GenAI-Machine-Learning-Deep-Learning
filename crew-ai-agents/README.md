# CrewAI Agent Builder – VS Code Project

This project converts a Colab-based CrewAI notebook into a production-ready
VS Code project.

## Features
- Modular CrewAI architecture
- Custom Ollama LLM integration
- Multi-agent workflows
- Dedicated summarization agent (30–40 lines)

## Run
```bash
pip install -r requirements.txt
python src/main.py
