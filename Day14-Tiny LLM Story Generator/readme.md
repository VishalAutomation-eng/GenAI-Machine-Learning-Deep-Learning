# Python-Only GPT-2 Inference Engine

## Assignment: Code-Focused Inference

This project loads a pretrained GPT-2 model and restricts it to answer
only Python coding-related questions using prompt-based filtering.

## Features
- GPT-2 inference (no training)
- Prompt filtering for Python questions
- Rejects non-coding queries

## Run Instructions

```bash
pip install -r requirements.txt
python src/main.py
